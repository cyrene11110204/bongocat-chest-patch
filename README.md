# BongoCat 补丁说明

替换游戏 `BongoCat_Data/Managed/Assembly-CSharp.dll` 即生效（先备份原文件）。

## Patch/Assembly-CSharp.dll

- **宝箱自动领取**：装扮宝箱就绪后自动开箱，无需点击；表情宝箱不受影响，绝不自动开
- **只保留皮肤奖励**：开箱结果只有 Skin 弹窗/自动佩戴，开到帽子等其他物品静默入库存
- **计时器修复**：原版键盘无输入时倒计时会停，此补丁修复该问题
- 宝箱冷却保持原版 30 分钟

## Patch2/Assembly-CSharp.dll

- 包含 Patch 的全部功能
- **宝箱冷却 30 分钟 → 1 分钟**：库存里攒的宝箱令牌（上限 10 个）会以每分钟一个的速度自动开掉

## 注意

- 令牌由 Steam 服务器按游戏时长投放，客户端无法加速；缩短冷却只是加快消耗存量
- Steam「验证文件完整性」会还原官方 DLL，需重新复制
- 详细原理与重新构建方法见 `PATCHES.md`
